# VoxMorph — מזיז פיץ' ופורמנטים לקול

פלאגין AU / VST3 למק, שבנוי על אותה שיטה של מזיזי קול קלאסיים: TD-PSOLA.

## איך זה עובד

1. **זיהוי פיץ'** — אלגוריתם YIN מזהה את התו של הקול כל 5 מילישניות.
2. **סימון מחזורים** — כל מחזור של מיתרי הקול מקבל סימון, בדיוק על השיא של הגל.
3. **הרכבה מחדש** — הקול נחתך ל"גרגרים" של שני מחזורים, והם מורכבים מחדש במרווח חדש: מרווח צפוף יותר = קול גבוה יותר, מרווח רחב יותר = נמוך יותר. כל גרגר שומר על הצורה שלו, ולכן צבע הקול (הפורמנטים) נשמר.
4. **פורמנט** — כל גרגר נדחס או נמתח לפני ההרכבה, וזה מזיז את צבע הקול בלי לשנות את התו.
5. **עיצורים ונשימות** (ס', ש', אוויר) עוברים בלי שינוי פיץ', רק עם שינוי הפורמנט.

## המצבים

- **TRANSPOSE** — מזיז את הפיץ' לפי הכפתור (±12 חצאי טונים).
- **QUANTIZE** — מצמיד כל תו לחצי הטון הקרוב (אוטו־טיון "קשה"). כפתור ה־Pitch מזיז את הכל לפני ההצמדה.
- **ROBOT** — כל השירה יוצאת על תו אחד, לפי כפתור Robot Note.

## הכפתורים

- **Pitch** — הזזת פיץ' בחצאי טונים
- **Formant** — צבע הקול: למעלה = קטן/צ'יפמאנק, למטה = גדול/מפלצת
- **Link** — הפורמנט זז יחד עם הפיץ' (אפקט "הקלטת הקלטה מהירה")
- **Robot Note** — התו במצב Robot
- **Drive** — סטורציה חמה על הקול המעובד
- **Mix** — יחס בין המקור לאפקט
- **Output** — עוצמת יציאה

התצוגה באמצע מראה את התו שנכנס ואת התו שיוצא.

## שימו לב

- הפלאגין מיועד לקול **מונופוני** אחד (שירה, דיבור, כלי סולו), לא לאקורדים.
- יש השהיה של כ־55 מילישניות. ה־DAW מפצה עליה אוטומטית בניגון, אבל בהקלטה בזמן אמת עם מוניטור דרך הפלאגין תשמע עיכוב.
- טווח הזיהוי הוא 80–1000 הרץ.

## בנייה

הבנייה נעשית אוטומטית ב־GitHub (לשונית Actions), או על המק:
`cd VoxMorph && cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j8`
